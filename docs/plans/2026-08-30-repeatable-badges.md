# 功能计划:可重复获得的成绩徽章

- 日期:2026-08-30
- 状态:已实现

## 背景

原徽章体系一次解锁终身拥有,"50 次打卡"达成后就没有动力了。
目标:让有累积属性的徽章可以重复获得,徽章右上角显示获得次数。

## 哪些徽章可重复(判定标准:能否自然累积)

| 徽章 | 重复规则 | 次数公式 |
|---|---|---|
| 连续7天 / 30天 / 百日 | 最长连续每满一段周期 | `floor(最长连续 / 7/30/100)` |
| 50次 / 500次打卡 | 累计打卡数每满一档 | `floor(累计打卡 / 50/500)` |
| 能量500 / 能量2000 | 累计能量每满一档 | `floor(能量 / 500/2000)` |
| 完美一周 | 每个全勤完整周 | 从最早记录日起逐周判定 `dayRatio==1` |

一次性徽章(首目标、早起鸟、夜猫子、十全十美、月度之星、全能周、习惯之王)不重复。

## 关键决策:次数是派生值,不落库

次数永远由当前数据实时计算,不存储。
好处:**不可能出现"计数与数据不一致"**(此前补签功能就出过数据不一致缺陷);
代价:每次渲染成就页多几次遍历——数据量下可忽略。

## 展示

- 右上角小圆片角标(`×N`,≥100 显示 99+),仅"已解锁且次数 >1"时显示
- 无障碍:`aria-label="连续7天已解锁,已获得 3 次"`(完整语义,非裸数字)

- [x] 能量500(单次档)不显示角标
- [x] 徽章本体视觉不变,角标不换行、不遮挡
