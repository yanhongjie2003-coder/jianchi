# 功能计划:热力图点击查看当日明细

- 日期:2026-08-30
- 状态:已实现

## 背景与目标

热力图只能"看颜色",用户想知道某一天具体打了什么卡。
目标:点击任意日期格子,就地展开该日各目标的打卡明细,不打断浏览。

## 设计要点

1. **就地展开,不用弹窗**:详情面板插入热力图卡片内部(legend 之上),
   选择信息保留在页面上下文中。
2. **选中态与"今天"描边共存**:`.heat.sel` 用 tertiary 色 outline,
   `.heat.today` 用 primary 色,互不冲突。
3. **再次点击同一格子 = 收起**(toggle),切换月份自动清除选中。
4. **计数型目标语义精确**:当日次数 >0 但未达 perDay 显示"进行中 5/8",
   而不是笼统的"已完成"——这是实现后自查发现的语义问题,一并修正。
5. **未来日期不可点**:格子加 `.off`(opacity .35, cursor default),不带 data-date。

## 数据与实现

- 选中状态:`let heatSel = null`(render.js),值为日期字符串
- 事件:事件委托挂在 `#heatGrid` 上(`e.target.closest(".heat")`)
- 判定:目标当日有记录 = `counts[date] > 0` 或 `history.includes(date)`
- 渲染:`renderHeatDetail()` 重建 `#heatDetail` 内容

## 验收

- [x] 点击无记录日:显示"这一天没有打卡记录"
- [x] 再次点击收起;切换月份清空选中
