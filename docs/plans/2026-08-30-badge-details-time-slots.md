# 功能计划:修复死徽章 + 徽章详情弹层

- 日期:2026-08-30
- 状态:已实现

## 背景

成就体系中有两枚"死徽章":

- **早起鸟**:只被演示数据预置解锁,没有任何运行时触发条件
- **夜猫子**:`flags.nightOwl` 永远不会被设置,永远无法解锁

死徽章对用户是负反馈("这个成就我这辈子拿不到")。同时,徽章只能看名字猜条件,
不点击就不知道怎么解锁。

## 方案

### 1. 时段打卡记录(数据层)

打卡历史只存日期,没有时刻——早起/夜间判定需要时刻。为此给每个目标增加
`daySlot[日期] = "early" | "night" | "none"`:当天**首次**打卡时按
`new Date().getHours()` 判定并写入(`<9` 早起,`≥22` 夜间),当天后续打卡不再覆盖。

- 存储最小:每目标每天最多一个标记
- 撤销回滚当天记录时,`daySlot` 同步删除,计数自然回退(延续"派生优于存储")
- 徽章次数 = 遍历所有 `daySlot` 值统计,早起鸟 / 夜猫子升级为**可重复徽章**(按天计)

### 2. 徽章详情弹层(交互层)

- 每枚徽章在 `badges.js` 定义 `desc`(条件文案)与 `progress()`(实时进度)
- 徽章渲染为 `<button data-badge="id">`,事件委托挂在 `#badgeGrid`
- 点击(含未解锁)弹出详情:图标、名称、解锁状态与次数、**条件描述**、**当前进度**
- 关闭:知道啦按钮 / 遮罩 / Esc
