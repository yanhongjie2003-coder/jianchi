# 变更日志

## v1.2.0 — 2026-08-30

### 变更
- **默认数据改为全空**:新用户从空状态开始,点 + 创建第一个目标即起步
- 默认用户名改为「简友」,头像自动取名字首字
- 数据页新增**本机备份**:一键保存当前数据快照到软件内,随时一键恢复(数据不出设备)

### 移除
- "重置演示数据"选项(由本机备份取代)

## v1.1.0 — 2026-08-30

### 功能
- **修复死徽章**:早起鸟 / 夜猫子接入真实判定——打卡时记录当天首次打卡时段(9 点前 / 22 点后),
  变为可重复徽章(按天计次数);撤销当天记录时段同步回退
- **徽章详情**:点击任意徽章(含未解锁)弹出详情层,展示解锁条件、当前进度与获得次数

## v1.0.0 — 2026-08-30


首个公开版本。

### 功能
- 目标管理:每日 / 每周 / 每月目标;计数型目标(如喝水 8 杯);创建、编辑、删除(二次确认)
- 打卡:庆祝弹窗、撤销(弹窗内或点击已打卡卡片)、连续天数、能量体系、8 级等级
- 统计:‹ 年月 › 任意切换,热力图点击查看当日明细,周概览、目标完成率
- 成就:15 枚徽章,7 类可重复获得(右上角 ×N 角标)
- 个性化:Material You 动态取色(5 种子色)、深色模式、减少动效、自定义名字与头像(可自动取名字首字)
- 数据:导出 / 导入 JSON、清空数据、重置演示数据,localStorage 持久化
- Android:极简 WebView 壳(GitHub Actions 自动打包 APK)

### 测试
- 17 组 GUI 黑盒测试点;发现 8 个缺陷(含 2 个严重:可无限刷能量、每日目标重复计数),修复 7 个(详见 testing-report.md)
